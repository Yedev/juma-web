# API 完整参考文档

为了方便管理和阅读，API 接口文档已按照不同功能模块拆分为多个独立文件：

## 目录

- [通用说明与错误码](./api-general.md)
  - 包含：通用响应格式、接口签名计算方式、健康检查、错误码说明等基础内容。
- [认证接口](./api-auth.md)
  - 包含：管理员登录等身份认证相关接口。
- [移动端 API](./api-app.md) 
  - 前缀：`/api/v1/app`
  - 包含：移动端应用配置、任务执行与状态查询。
- [管理后台 API](./api-admin.md)
  - 前缀：`/api/admin`
  - 包含：后台任务管理、执行器客户端管理、配置管理、DeepRead 后台管理等。
- [DeepRead 客户端 API](./api-dr.md)
  - 前缀：`/api/v1/dr`
  - 包含：用户注册登录、空间、文章、批注、合集等核心业务接口。
